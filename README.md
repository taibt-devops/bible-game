# Manna – Học thuộc câu gốc

Game nhẹ (HTML/CSS/JS thuần, không cần build) để giới trẻ học thuộc câu gốc Kinh Thánh.

- Chạy thử: mở `index.html` hoặc `python3 -m http.server`.
- Thêm câu gốc: sửa `verses.js` (nên đối chiếu với bản Kinh Thánh bạn dùng).
- Chế độ: Điền từ, Xếp câu, Gõ thuộc lòng, Ôn tập (thẻ ghi nhớ). XP, cấp độ, chuỗi ngày và số sao lưu trong localStorage.
- Có thể deploy thẳng lên Cloudflare Pages / GitHub Pages.
